## Navigation

| Shortcut | Action |
| --- | --- |
| **Cmd+K** / **Ctrl+K** | Open the [command palette](/ai-and-search/command-palette) — search, go to a page, open a setting, or ask Bower |
| **Tab** (in the palette) | Hand what you've typed to Bower |

## Workspace

### Collections and files

| Shortcut | Action |
| --- | --- |
| **Arrow keys** | Move between items |
| **Shift+Arrow** / **Shift+click** | Extend the selection |
| **Cmd+click** | Add or remove one item from the selection |
| Drag on empty space | Select a group of items with a rectangle (Folder and Card views) |
| **Cmd+A** | Select every loaded item |
| **Enter** | Open the item. In List view, a single click also opens a row; select rows with their checkbox |
| **F2** | Rename in place. **Enter** saves; **Escape** or clicking away cancels |
| **Cmd+C** / **Cmd+X** | Copy or cut the selected items |
| **Cmd+V** | Paste into the open collection. A copy makes duplicates; a cut moves the items and offers **Undo**. Cut items look faded until pasted; **Escape** cancels a cut |
| **Delete** | Move the selected items to Trash, after you confirm |
| **Shift+F10** or the context menu key | Open the item's menu, same as right-click |
| Right-click on empty space | Open the **Add** menu, plus **Paste** when something is copied |
| **Escape** | Clear the selection |

### Page tree

| Shortcut | Action |
| --- | --- |
| **Alt+Up** / **Alt+Down** | Move the focused collection or file up or down among its siblings |

### List view columns

| Shortcut | Action |
| --- | --- |
| **Left** / **Right** on a column's drag handle | Move the column one place. Click the handle for a **Move left** / **Move right** menu |

## Text editing

| Shortcut | Action |
| --- | --- |
| **Cmd+B** | Bold |
| **Cmd+I** | Italic |
| **Cmd+U** | Underline |
| **Cmd+E** | Inline code |
| **Cmd+Shift+X** | Strikethrough |
| **Cmd+Z** | Undo |
| **Cmd+Shift+Z** | Redo |

## Saving and printing

| Shortcut | Action |
| --- | --- |
| **Cmd+S** | Save the note now. Bower saves automatically as you type, so this is a reassurance rather than a requirement; the [save indicator](/capture/editor#autosave) shows the result |
| **Cmd+P** | Print the whole note, or save it as a PDF from the print dialog |

## Tables

| Shortcut | Action |
| --- | --- |
| **Cmd+Shift+T** | Insert a table |
| **Tab** / **Shift+Tab** | Move to the next / previous cell |
| **Cmd+Shift+Right** / **Cmd+Shift+Left** | Add a column after / before |
| **Cmd+Shift+Down** / **Cmd+Shift+Up** | Add a row after / before |
| **Cmd+Shift+Delete** | Delete the current column |
| **Cmd+Alt+Delete** | Delete the current row |
| **Cmd+Shift+M** | Merge the selected cells |
| **Cmd+Shift+S** | Split the current cell |

See [Tables](/capture/editor#tables) for resizing, coloring and fitting a table to the page.

## Block insertion

Type `/` at the start of a new line to open the [slash command menu](/capture/editor#slash-commands). Then type to filter:

| Type | To insert |
| --- | --- |
| `/h1` | Heading 1 |
| `/h2` | Heading 2 |
| `/h3` | Heading 3 |
| `/bullet` | Bullet list |
| `/numbered` | Numbered list |
| `/task` | Task list |
| `/table` | Table |
| `/code` | Code block |
| `/quote` | Blockquote |
| `/hr` | Divider |
| `/image` | Image upload |

<Note>
All shortcuts use **Cmd** on Mac and **Ctrl** on Windows/Linux.
</Note>
