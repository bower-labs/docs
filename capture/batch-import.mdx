Upload up to 20 files at once. Bower turns documents, recordings and images with text into editable notes, and keeps everything else as searchable attachments.

## What happens to each file type

Mixed batches are fine, so you don't need to sort files by type before you upload them.

| File type | What Bower does |
| --- | --- |
| Word documents (.docx, .doc) | Converted to an editable note. Tables, text color and highlighting are kept. |
| Voice recordings and audio (.m4a, .mp3, .wav, .aac, .flac, .ogg) | Transcribed into a note, with scientific vocabulary recognition. |
| Plain text and Markdown (.txt, .md) | Read directly into a note. |
| Images (.jpg, .png, .heic, .webp, .tiff and more) | Bower reads text, tables, equations and figure regions. If it finds text, it creates an editable note. A photo or figure with no text stays an attachment, searchable by its AI-generated description. |
| PDFs | The text is extracted, with OCR for scanned pages, so the PDF is searchable. It stays an attachment. To get an editable note, open the attachment, click **More options**, then **Convert to Note**. |
| Videos (.mp4, .mov, .m4v, .avi) | Saved as a playable attachment, up to 10 minutes long. Video is not transcribed. |
| Code files | Saved as an attachment, with its contents searchable. |
| CSV and Excel (.csv, .xlsx) | Saved as an attachment. In workspaces with spreadsheets turned on, they become editable spreadsheets instead (.xlsm files, and files over 25 MB for .xlsx or 16 MB for .csv, stay attachments). |
| Anything else (.zip and so on) | Saved as an attachment you can find by its file name. |

When a file becomes a note, the original file is attached to that note, so nothing is discarded.

## How to import

<Steps>
  <Step title="Open the import dialog">
    Click **Create** and select **Import files**. To import straight into a collection, open it, click **Add**, and select **Import files**. You can also use **Import** in the **New** menu on your notes page.
  </Step>
  <Step title="Select your files">
    Drag files onto the dialog or click to browse. You can import up to **20 files** at a time, with a maximum of **500 MB per file**.
  </Step>
  <Step title="Keep working">
    Click **Upload**. The files upload and process in the background, and you can follow their progress in the upload tray while you carry on with something else.
  </Step>
</Steps>

Already keep your notes in OneNote, Notion, Google Drive or OneDrive? Use the link in the import dialog to set up a [connector](/integrations/connectors) and import them directly.

## Limits

| Limit | Value |
| --- | --- |
| Files per import | 20 |
| Max file size | 500 MB per file |
| Max video length | 10 minutes |

## Importing into the protocol library

When you import from the protocol library, Word documents, text files and audio recordings become protocols. Images with text become notes, and every other file type is saved as an attachment.

## After import

- Each note and attachment is searchable as soon as processing finishes.
- Images are searchable by their AI-generated description, so you can find a photo of a gel by searching for "gel electrophoresis" even if the file is called `IMG_4382.jpg`.
- Equations are kept as editable mathematical notation when Bower can recognize them.
- Diagrams and other figure regions appear inline as crops from the source image, in reading order. Bower does not redraw them.
- Extracted tables are editable inline.
- Bower can summarize, compare or cross-reference your imported notes as soon as processing finishes.

## A note on quality

Printed text extracts most reliably. Handwriting and instrument displays are harder to read, so check those notes against the original, which is always attached. You always have the final say.
