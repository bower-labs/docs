Every note in Bower opens in a rich text editor. You can type freely, format text, insert tables and images, and use slash commands for quick block insertion.

## Text formatting

The toolbar at the top of the editor provides:

| Action | Shortcut |
| --- | --- |
| **Bold** | Cmd+B |
| *Italic* | Cmd+I |
| Underline | Cmd+U |
| ~~Strikethrough~~ | Cmd+Shift+X |
| `Code` | Cmd+E |
| Highlight | Cmd+Shift+H |
| Text color | Toolbar color picker |

Select text to reveal a **floating toolbar** with every formatting option, including text color and font family.

## Headings

Use the heading dropdown in the toolbar, or `/h1`, `/h2` and `/h3`. Headings also build the [Table of Contents](#table-of-contents).

## Slash commands

Type `/` at the start of a new line to open the command menu, then keep typing to filter: `/math` shows the math commands.

### Style

| Command | What it inserts |
| --- | --- |
| `/text` | Plain paragraph |
| `/h1` | Heading 1 |
| `/h2` | Heading 2 |
| `/h3` | Heading 3 |
| `/bullet` | Bullet list |
| `/numbered` | Ordered list |
| `/task` | Task list with checkboxes |
| `/quote` | Blockquote |
| `/code` | Code block |
| `/callout` | Info callout box (blue) |
| `/warning` | Warning callout box (amber) |
| `/tip` | Tip callout box (green) |
| `/toggle` | Collapsible toggle section |

### Insert

| Command | What it inserts |
| --- | --- |
| `/table` | 3x3 table with header row |
| `/hr` | Horizontal divider |
| `/image` | Image upload dialog |
| `/diagram` | Open the diagram editor |
| `/math` | Inline LaTeX equation |
| `/equation` | Block LaTeX equation (centered) |

### Align

Alignment is also in the toolbar.

| Command | What it does |
| --- | --- |
| `/align left` | Left-align text |
| `/align center` | Center text |
| `/align right` | Right-align text |
| `/justify` | Justify text |

## Lists

Insert a bullet, numbered or task list with its slash command or the toolbar. Task lists nest: press Tab to indent a task under another.

## Callout boxes

`/callout`, `/warning` and `/tip` insert an **Info**, **Warning** or **Tip** box with a colored left border and tinted background. Type inside it to add your content.

## Collapsible toggles

`/toggle` inserts a collapsible section: a summary line beside a triangle, and content below it that shows when you click the triangle.

## Tables

Insert a table with `/table` or Cmd+Shift+T. Tables start as 3x3 with a header row.

- **Resize columns** -- drag any column border, including the table's
  right-hand edge
- **Fit to width** -- in the table handle menu, beside duplicate and delete.
  The quickest way to tame a wide or extracted table
- **Banded rows** -- alternating row shading, from the table options menu or
  Cmd+Shift+K
- **Select cells** -- click and drag across cells
- **Act on several rows at once** -- select whole rows, then delete, insert or
  clear their contents; the action applies to everything you selected
- **Scroll** -- a table wider than the editor scrolls horizontally, with a
  scrollbar above the table as well as below, so the right-hand columns stay
  reachable while you are reading the header

Adding and deleting rows and columns, merging and splitting cells, and moving
between cells all have [keyboard shortcuts](/capture/keyboard-shortcuts#tables).
The table controls stay visible while your cursor is anywhere in the table.

<Note>
  Banded rows are a screen and share-link feature. They are not carried into
  Word or PDF export, so a banded table prints unbanded. Duplicate, sort and
  alignment act on the row you are hovering rather than on a multi-row
  selection.
</Note>

Table cell and header shading survives a round trip through Word export and
import.

## Mathematics (LaTeX)

Write mathematical equations using LaTeX syntax, rendered with KaTeX:

- `/math` -- insert an **inline equation** that flows with surrounding text
- `/equation` -- insert a **block equation** displayed as a centered formula

Click on any rendered equation to edit the LaTeX source.

## Images

Insert images with `/image` or the toolbar button. You can also drag and drop images directly into the editor, or paste from your clipboard.

Uploaded images support:

- **Resizing** -- drag the corner handles
- **Alignment** -- left, center, right via the floating toolbar
- **Annotation** -- draw on images with shapes, arrows, and text
- **Lightbox** -- click an image in read-only mode to expand it

### Annotating images

Click an inline image, then the **draw icon** in the floating toolbar, to draw on it. See [Image Annotations & Diagrams](/capture/annotations-and-diagrams).

## Diagrams

Type `/diagram` or click the **draw icon** in the fixed toolbar to draw a diagram from scratch, with shapes, arrows, text, freehand tools and a library of scientific shapes. See [Image Annotations & Diagrams](/capture/annotations-and-diagrams).

## Code blocks

Insert a code block with `/code` or type ` ``` ` followed by Enter.

## Block quotes

Insert a block quote with `/quote` or type `>` followed by a space.

## Links

Select text and press Cmd+K to add a hyperlink. Click an existing link to edit or remove it.

## Emoji

Type `:` followed by the emoji name (e.g. `:wave:`) to insert an emoji. Standard emoticons like `:)` and `:D` are auto-converted.

## Table of Contents

On wide screens (1280px+), a **Table of Contents** appears at the right edge of the editor:

- Small **dash indicators** show each heading at a glance
- **Hover** to expand a full heading outline panel
- **Click** any heading to scroll to that section
- The **active heading** is highlighted as you scroll

The Table of Contents updates automatically as you add, remove, or rename headings.

## Drag and drop blocks

Every block has a **drag handle** (six-dot icon) in the left gutter on hover:

- **Click** the handle to select the entire block (for copy/cut)
- **Drag** the handle to reorder blocks

The **+** button next to the drag handle opens the slash command menu.

## Markdown input

Markdown you type converts to rich text:

- `# Heading` to H1, `## Heading` to H2
- `- item` or `* item` to bullet list
- `1. item` to numbered list
- `> quote` to block quote
- `**bold**` to bold, `*italic*` to italic
- `` `code` `` to inline code
- `---` to horizontal rule

Pasted Markdown converts the same way.

## Undo and redo

Use **Cmd+Z** to undo and **Cmd+Shift+Z** to redo. The toolbar also has undo/redo buttons.

## Page width

A note reads in a centered column. For wide tables or dense text, switch the page to full width. The choice is saved on the page, so everyone who opens it sees the same width.

Switch it from either of two places:

- The **width icon** at the right end of the toolbar row, next to undo, redo, image, diagram and attach.
- The **Full width** switch in the **&#8942;** (kebab) menu, just below Version history.

Only an editor can change the width. Viewers and guests see the saved width, but the switch in the kebab menu is disabled for them.

The width toggle isn't offered on small screens (roughly under 1024px wide), where the reading column already fills the available space.

Version history and exports to PDF and Word always use the standard reading width, regardless of the page's current setting.

## Autosave

Your content is saved automatically as you type, within seconds of your last edit. You do not need to save.

### The save indicator

A small cloud icon sits in the top bar of every note and protocol, just left of the **&#8942;** (kebab) menu, so you can see where your work stands without opening anything. Hover it, or tap it on a touchscreen, for the detail, including the time of the last save.

| Icon | What it means |
| ---- | ------------- |
| Cloud with a tick | Saved. |
| Cloud with arrows | Saving. Your most recent edit is on its way. |
| Crossed-out cloud, in red | Not saved. See below. |

The indicator only appears if you can edit the page. A read-only viewer has nothing to save.

### If the indicator turns red

Your most recent changes have not reached Bower, and **closing the page will lose them**. Check your internet connection, then choose **Save** from the **&#8942;** menu to try again.

Your work stays in the editor in the meantime, so you can keep typing. Carrying on will start a fresh save attempt on its own.

### Closing or reloading the page

If you close or reload the page while a change is still saving, or has not saved, your browser asks you to confirm before you leave. Stay on the page and Bower finishes the save; the indicator shows when it is done. Leaving anyway can lose that change.

### Saving by hand

You rarely need to, but **Save** in the **&#8942;** menu, or **Cmd+S** (Ctrl+S on Windows and Linux), forces an immediate save. It is worth using before you close the tab on an unreliable connection. When nothing is pending, Cmd+S just confirms that everything is already saved.

## Voice to Text

Click **Voice to Text** on a note to record speech, such as a meeting or a spoken observation, and have Bower transcribe it into the note. When you're done, click **Stop & insert**. The transcript is inserted at your cursor.

### Keep the tab open while it saves

After you stop, Bower uploads the recording. While it does, you'll see **Saving your recording. Keep this tab open.** The transcript appears in the note once the recording has saved.

While you record and while it saves, Bower keeps a copy of the recording in this browser on this device. If the upload doesn't finish, that copy is how you get the recording back.

If you see **This recording isn't backed up on this device**, Bower couldn't keep that copy. Keep the tab open until the recording has saved: if the tab closes first, the recording can't be recovered.

### If a recording wasn't saved

If the tab closes, your laptop goes to sleep, the browser crashes, or you're signed out before a recording finishes saving, the next time you open Bower in that browser you'll see **A recording wasn't saved**. It can appear on any page, not only the note.

To help you tell which recording it is, the message shows:

- The note the recording belongs to, or **A note you can no longer open** if that note has been deleted or you no longer have access to it.
- When it was recorded (the date and time) and how long it is.
- A player, so you can listen to it before you choose what to do.

Then choose:

- **Upload to note** adds the recording to the note it was recorded in. Keep the tab open until it finishes. The transcript appears in that note.
- **Discard**, with the bin icon, asks you to confirm first. A discarded recording is deleted from this device and can't be recovered.
- The **X** in the top right closes the message without choosing. Bower asks again the next time you open it. You can't close the message while a recording is uploading.

If the upload fails, the message says so and offers **Try again**.

If the message says **Only the first part of it was saved on this device**, Bower can upload what it kept, but the rest of the recording is lost.

A few things to know:

- Only the person who made the recording is offered it. Anyone else who signs in to Bower in the same browser won't see it.
- The copy lives in the browser you recorded in. Opening Bower in a different browser or on a different device won't show it.
- Unsaved recordings are deleted 7 days after you started recording, the next time you open Bower in that browser. Upload a recording within a week if you want to keep it.

## Export

Notes can be exported from the note menu in multiple formats:

- **Word** (.docx) -- headings, lists, tables with their cell colors, images and code blocks, built in your browser without the note leaving it
- **Markdown** (.md)
- **Plain text** (.txt)
- **PDF** (via browser print)

**Cmd+P** prints the whole note, not just the part on screen, and the print dialog can save it as a PDF.
