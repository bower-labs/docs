Every note in Bower opens in a rich text editor. Keyboard shortcuts for everything below are listed in [Keyboard shortcuts](/capture/keyboard-shortcuts). To have Bower make a change for you, such as filling a table cell or ticking a task, see [Ask Bower to edit a note](/ai-and-search/editing-notes-with-bower).

## Text formatting

The toolbar at the top of the editor, and a floating toolbar that appears when you select text, offer bold, italic, underline, strikethrough, inline code, highlight, text color, font family, and alignment (left, center, right, justify).

Use the heading dropdown in the toolbar to switch between paragraph text and three heading levels.

## Slash commands

Type `/` at the start of a new line, or click **+** beside a block, to open the command menu. Type after the slash to filter, for example `/math`.

| Command | What it inserts |
| --- | --- |
| `/text`, `/h1`, `/h2`, `/h3` | Paragraph or heading |
| `/bullet`, `/numbered`, `/task` | Bullet, numbered or task list |
| `/quote` | Blockquote |
| `/code` | Code block |
| `/callout`, `/warning`, `/tip` | Info (blue), warning (amber) or tip (green) callout |
| `/toggle` | Collapsible section: click the triangle to expand or collapse it |
| `/table` | 3×3 table with a header row |
| `/hr` | Horizontal divider |
| `/image` | Image upload dialog |
| `/diagram` | The diagram editor |
| `/math` | Inline LaTeX equation |
| `/equation` | Centered block LaTeX equation |
| `/align left`, `/align center`, `/align right`, `/justify` | Text alignment |

## Markdown input

Markdown you type or paste converts to rich text as you go:

| Type | To get |
| --- | --- |
| `#`, `##` and a space | Heading 1, heading 2 |
| `-` or `*` and a space | Bullet list |
| `1.` and a space | Numbered list |
| `>` and a space | Blockquote |
| ` ``` ` and Enter | Code block |
| `**bold**`, `*italic*`, `` `code` `` | Bold, italic, inline code |
| `---` | Horizontal divider |

Type `:` and a name to insert an emoji; `:)` and `:D` convert automatically.

## Lists

Bullet, numbered and task lists come from the slash menu or the toolbar. Task list items have checkboxes; press Tab to nest a task under another.

## Tables

Insert a table with `/table`. Tables start as 3×3 with a header row.

- **Resize columns** by dragging any column border, including the right-hand edge.
- **Fit to width**, in the table handle menu beside duplicate and delete, is the quickest way to tame a wide or extracted table.
- **Banded rows** shade alternate rows, from the table options menu.
- **Select cells** by dragging across them; merge and split them from the keyboard.
- **Select whole rows** to delete, insert or clear them together. Duplicate, sort and alignment act on the row you are hovering, not on a multi-row selection.
- A table wider than the editor scrolls sideways, with a scrollbar above the table as well as below.

The table controls stay visible while your cursor is in the table, and every handle has a tooltip. For what tables keep in Word and PDF, see [Exporting notes](/organisation/export).

## Mathematics (LaTeX)

`/math` inserts an inline equation and `/equation` a centered block equation, both rendered with KaTeX. Click a rendered equation to edit its LaTeX, for example `\frac{a}{b}` or `\begin{pmatrix} a & b \\ c & d \end{pmatrix}`.

## Images

Insert an image with `/image` or the toolbar button, or drag and drop or paste one into the note. Drag the corner handles to resize it, set its alignment from the floating toolbar, and click it in read-only mode to view it full size.

To draw on an image, click it, then the **draw icon** in the floating toolbar. For drawing on images and creating diagrams with `/diagram`, see [Image annotations and diagrams](/capture/annotations-and-diagrams).

## Links

Select text and press Cmd+K to add a link. Click a link to edit or remove it.

## Table of Contents

On screens 1280 px wide or more, a **Table of Contents** sits at the right edge of the editor. Each heading shows as a dash; hover to see the outline, and click a heading to scroll to it. The heading you're reading is highlighted.

## Moving blocks

Hover a block to show its drag handle (six dots) in the left margin. Click the handle to select the block for copying or cutting, or drag it to move the block.

## Page width

A note reads in a centered column by default. For wide tables or dense text, switch the page to full width with either:

- the **width icon** at the right end of the toolbar, or
- the **Full width** switch in the **&#8942;** menu, below Version history.

The setting is saved on the page, so everyone sees the same width. Only members who can edit the page can change it. The switch isn't offered on screens narrower than about 1024 px. Version history and PDF and Word exports always use the standard width.

## Autosave

Bower saves within seconds of your last edit. If you can edit the page, a cloud icon left of the **&#8942;** menu shows where your work stands; hover or tap it to see the time of the last save.

| Icon | Meaning |
| ---- | ------- |
| Cloud with a tick | Saved |
| Cloud with arrows | Saving your latest edit |
| Crossed-out cloud, in red | Not saved |

**If the icon is red**, your latest changes haven't reached Bower and closing the page will lose them. Check your connection, then choose **Save** from the **&#8942;** menu. You can keep typing; your work stays in the editor, and the next edit tries again.

If you close or reload the page while a change is unsaved, your browser asks you to confirm. Stay on the page to let the save finish.

**Save** in the **&#8942;** menu, or Cmd+S, saves immediately. It's worth using before closing a tab on an unreliable connection.

## Voice to text

Click **Voice to text** on a note to record speech, such as a meeting or a spoken observation, and have Bower transcribe it. Click **Stop & insert** when you're done; the transcript is inserted at your cursor once the recording has uploaded.

While it uploads you'll see **Saving your recording. Keep this tab open.** Until then, Bower keeps a copy of the recording in this browser on this device. If you see **This recording isn't backed up on this device**, there is no copy, so keep the tab open until the save finishes or the recording is lost.

### If a recording wasn't saved

If the tab closes, the computer sleeps, the browser crashes or you're signed out before a recording saves, the next time you open Bower in that browser you'll see **A recording wasn't saved**, on any page. It shows the note the recording belongs to (or **A note you can no longer open**), when it was recorded, its length, and a player.

| Choose | What happens |
| --- | --- |
| **Upload to note** | Adds the recording to its note and transcribes it. Keep the tab open until it finishes. If it fails, choose **Try again**. |
| **Discard** | After you confirm, deletes the recording from this device for good |
| **X** | Closes the message; Bower asks again next time |

If the message says **Only the first part of it was saved on this device**, you can upload what was kept; the rest is lost.

The saved copy is only offered to the person who recorded it, and only in the browser they recorded in. It is deleted 7 days after recording started, so upload it within a week.

## Image to text

Click **Image to text** on a note and choose an image, such as a page of a lab notebook or a printed label. Bower attaches the image to the note, reads the text in it, and adds that text to the note. You can keep working while it reads, and add more images.

If Bower can't read an image, the image stays attached to the note. To try again, open **Attachments**, click the **&#8942;** menu on the image and choose **Image to text**.

## What the Voice to text and Image to text buttons show

Both buttons keep the same shape the whole time. Their color, icon and label tell you what is happening.

| The button shows | What it means |
| --- | --- |
| **Voice to text** or **Image to text** | Ready |
| Red, with a pulsing dot and **Recording 0:03** | The microphone is on. Stop it with **Stop & insert** in the recording panel |
| Blue, with a spinner: **Uploading…**, **Transcribing…** or **Reading image…** | Bower is turning your recording or image into text. The text appears in the note when it's done |
| Red, with **Retry upload**, **Upload failed**, **No transcript** or **Couldn't read** | The recording or image, or its text, didn't reach the note. Hover over the button to see why. **Retry upload** tries again, and after **Upload failed** click the button to choose the image again; to read or transcribe a saved file again, use its **&#8942;** menu under **Attachments** |

On a phone the buttons show only their icon, with a small badge for the state: a spinner while Bower works, a red dot when something failed, and a pulsing dot while recording.

## Export

Export a note from the note menu as Word, Markdown, plain text or PDF, or print it with Cmd+P. See [Exporting notes](/organisation/export).
