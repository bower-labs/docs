Opening a photo, a video or an audio recording shows it in the viewer, with what Bower knows about it beside the file.

## How do I page through captures?

When the file belongs to a set of two or more, a strip of thumbnails runs under it. Click a thumbnail, or use the arrows on either side of the file, to move to the next or previous capture. The set is one of these:

| Set | What it holds |
| --- | --- |
| **This run** | The captures from one [protocol run](/organisation/protocols#protocol-runs) |
| **This Live session** | The captures from one [Live](/ai-and-search/live-agent-mode) session |
| **This note** | The attachments on one note |
| **This folder** | The files in one collection |

When a file belongs to more than one set, such as a run's photo that is also on a note, choose the set from **Browse through** at the top of the strip.

A file opened beside a note shows on its own, with no strip. Click **Full Page** to page through the note's other attachments.

## Which keys work in the viewer?

A tip under the strip lists the keys for the file in front of you. The play, full screen and mute keys work once you've clicked the player.

| Key | Action |
| --- | --- |
| **←** / **→** | Previous or next capture |
| **+** | Zoom into a photo |
| **Space** or **K** | Play or pause a video or recording |
| **F** | Full screen (video) |
| **M** | Mute or unmute (video) |

The keys do nothing while you're typing, for example in a description.

## What is "What Bower sees"?

For a photo, Bower writes a short description of what it shows, labeled **What Bower sees** so it's never mistaken for text in the photo. If you can edit the file and the description is wrong, click the pencil (**Edit description**), correct it and save. A corrected description is marked **Edited**.

## Can I copy or correct the text Bower read?

Yes. Under **Text in this photo**, **Transcript** (for a recording) or **Text in this file**, use **Copy text** to copy it, or **Edit text** to correct it if you can edit the file.

For a file attached to a note, the text Bower read is in the note itself, so copy or correct it there. A photo on a note says which note holds its text.

## How do I use a Live clip's transcript?

A video or recording made during a Live session shows **Transcript** beside the player: what was said while it was recorded, from the session's [transcript note](/ai-and-search/live-run-transcripts).

- Click a line to play from about that moment. Times are approximate, because each line is timed from when it finished.
- While the clip plays, the current line is highlighted and the list follows it.
- Type in the search box to find a word. Press **Enter** for the next match and **Shift+Enter** for the previous one; **Escape** clears the search.

## How do I find the run step a capture was taken on?

A capture from a protocol run shows **Captured during** and the run under its title, such as **Captured during Run 3 · PCR setup**. To see the step too, open **Details**: its **Protocol run** row shows the run and step, such as **Run 3 · PCR setup, step 4**. Click it to open the run at that step.

## Where does a voice note's recording play?

At the top of the note. The note's text is transcribed from the recording, and you can edit it like any note.
