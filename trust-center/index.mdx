**Bower has a SOC 2 Type I report and a HIPAA Type I attestation**, both issued by the independent auditor [Advantage Partners](https://advantage-partners.com) on October 12, 2026, with an unqualified opinion and no exceptions noted. The auditor examined the controls protecting the Bower platform, including its safeguards for protected health information, as of August 21, 2026. Our SOC 2 Type II audit, which tests how those controls operate over time, is underway. [What the reports cover, and how to request them under NDA →](/trust-center/soc-2-and-hipaa)

For control documentation, security questionnaires, or a DPA, email [privacy@bowerlabs.ai](mailto:privacy@bowerlabs.ai). To start a BAA, email [legal@bowerlabs.ai](mailto:legal@bowerlabs.ai).

## Security overview

<CardGroup cols={3}>
  <Card title="AES-256 encryption" icon="lock">
    All data encrypted at rest using AES-256 and in transit via TLS, on every connection.
  </Card>
  <Card title="Workspace isolation" icon="shield-halved">
    Each workspace's data is isolated at the data layer, scoped to a single workspace beneath the application so cross-workspace access is blocked before any data is returned.
  </Card>
  <Card title="Audit logging" icon="clock-rotate-left">
    Every create, update, and delete action is logged with who, what, when, and field-level diffs. Exportable to CSV.
  </Card>
</CardGroup>

<CardGroup cols={3}>
  <Card title="Session management" icon="right-from-bracket">
    30-minute inactivity timeout. Revoke all sessions instantly from settings. Token expiry enforced server-side.
  </Card>
  <Card title="Role-based access" icon="users-gear">
    Four roles (Owner, Admin, Member, Guest) with strict hierarchy enforced at the API level.
  </Card>
  <Card title="AI data handling" icon="brain">
    **We do not use your identifiable content to train AI models**, and our providers are contractually barred from training on it too.
  </Card>
</CardGroup>

### Your data rights

- **Export**: download a complete copy of all your personal data as JSON from **Settings > Security > Export my data**
- **Delete**: permanently remove your account and all associated data from **Settings > Security > Danger Zone**
- **Cookie control**: choose exactly which cookies Bower uses, changeable at any time from **Settings > Security**
- **DPO contact**: reach our Data Protection Officer at [privacy@bowerlabs.ai](mailto:privacy@bowerlabs.ai)

## Infrastructure & sub-processors

All primary data is hosted on **Google Cloud Platform (us-central1)**. The summary below covers our main infrastructure and AI providers. See the [complete sub-processor list](/trust-center/sub-processors) for every provider, the data it processes, and its current DPA or BAA status. Restricted mode is a separate HIPAA control: it blocks protected content from providers without a signed BAA.
