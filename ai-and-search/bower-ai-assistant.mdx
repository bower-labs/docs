Bower is the AI assistant built into your workspace. It can read, search, create and organize your notes, collections and attachments, and search the literature and the web. Every answer cites its sources.

## What Bower can do

| Ask Bower to | For example |
| --- | --- |
| **Find** anything in your workspace, including voice transcripts, text extracted from photos, and imported files | *"Show me pH readings from last month"*, *"Find my notes on sample batch 14"* |
| **Find photos by place**, using where they were taken, even untitled ones | *"Find the photos I took at the field site in Bali"* |
| **Search the literature and the web**, across the [13 public sources](/integrations/connectors#13-always-on-sources-no-setup) | *"What's the latest research on coral alkalinity tolerance?"*, *"What did Jane Smith publish in 2025?"* |
| **Look up a record** for a gene, protein, compound or structure in public biology databases | *"What's the resolution of PDB 1TUP?"* |
| **Follow a citation trail** from papers you already know: the papers they cite and the papers that cite them, ranked by how closely connected they are | *"I'm reading these three papers. What else should I be reading?"* |
| **Summarize** one or more notes | *"Summarize this week's observations"* |
| **Compare** related notes side by side | *"Compare my alkalinity readings from this week and last week"* |
| **Create** notes, protocols and collections | *"Make a new collection called February Field Samples"* |
| **Edit a note**: fill table cells, tick tasks, change headings or formatting; see [Ask Bower to edit a note](/ai-and-search/editing-notes-with-bower) | *"Put 0.42 in the OD600 column for sample B3"* |
| **Organize**: move notes, link related items, add tags, rename | *"Move all my alkalinity notes into the Field Samples collection"* |
| **Process files**: extract text from images, transcribe audio, read PDFs and documents | *"Transcribe the audio from Tuesday's meeting"* |
| **Draft a run plan** from a set of notes and a protocol, for a formal experimental record | *"Draft a plan to run the PCR protocol on these samples"* |
| **Create an invite link** (owners and admins) | *"Create an invite link for the lab"* |
| **Update your profile**: display name or ORCID iD | *"Save my ORCID 0000-0001-2345-6789"*, *"Clear my ORCID iD"* |

When you save an ORCID iD in chat, Bower checks it against ORCID's public record, the same check the [Profile tab](/workspaces-and-account/manage-account#add-your-orcid-id) runs, and replies with the name it found so you can confirm it's yours. With an iD saved, Bower draws on your publication list when you ask about your own work.

When a captured value falls outside the expected range for a protocol parameter, Bower flags it after capture, explains why, and asks what you'd like to do.

The **Public sources** switch in the [connector picker](/integrations/connectors#picking-which-connectors-are-active-in-a-chat) turns all public sources off for every message until you turn it back on.

## Citations

Bower places a numbered marker such as **[1]** after each claim it draws from a source. Click the marker for the source details. A collapsible **Sources** section at the end of each reply lists every source used:

- **Workspace sources** link to the notes, protocols or attachments Bower used.
- **Web sources** show the page title and site icon, and link to the article, paper or record.

## How to use Bower

Bower chat is in the right-hand panel. Ask in plain language. To focus Bower on particular items, select notes or collections as **context chips** before you ask.

While Bower works, a line above the reply describes what it is doing, such as *Searching notes…* or *Looking up your publications on ORCID…*, so you can tell whether it is still searching or waiting on an outside service.

You don't have to wait for a reply to finish. While Bower is answering, you can open an earlier conversation with **Previous conversations** or start one with **New conversation**. A message tells you Bower is still answering in the conversation you left; the reply is there when you go back. The one exception is while files you attached are still uploading: both controls stay unavailable until your message has been sent.

### Attaching files

Attach a file to a message with the paperclip button, by dropping it on the chat input, or by pasting it, for example a screenshot. Attached files show as chips above the input; remove one with its **×**. Each file goes with that message only.

Bower accepts documents, images, spreadsheets, PDFs and research code, including `.R`, `.Rmd`, `.jl` and `.do` scripts. If a file is too large or of a type Bower can't read, a message names the file and the reason, and the rest still attach. A `.csv` or `.xlsx` file becomes a [spreadsheet](/organisation/spreadsheets) that Bower can answer questions about in the same message.

A photo of a gel, plate or instrument display can go straight into the chat without saving it first. A **table** copied out of a document pastes as text, not as an attachment; to have Bower read a table, attach the file or a photo of it.

### Voice dictation

Tap the **microphone button** in the chat input to dictate, then tap stop, review the text and send. In Chrome, Safari and Edge, the text appears as you speak. In Firefox, it appears shortly after you stop. If your browser doesn't support voice input, the button isn't shown.

For a spoken back-and-forth with video, use [live agent mode](/ai-and-search/live-agent-mode) on your phone or Bower Glasses.

## What Bower won't do

- Act on your data without permission. It suggests; you confirm.
- Open a web link without asking after its safety check blocked something. Bower usually opens the links it finds straight away. But if, earlier in the same answer, it blocked a source that tried to give it instructions (see below), it shows you the full address of any link it then wants and waits for **Open link** before visiting it. The Bower mobile app can't show this prompt yet, so there Bower tells you which link it wanted instead: paste it into a new message, or approve it from Bower on the web.
- Go online in a [Restricted mode](/trust-center/hipaa-compliance) workspace. There, Bower doesn't search the web, look up public research databases or open links, and it tells you so. It answers from your workspace instead.
- Present AI-extracted values as verified fact. It shows confidence where relevant.
- Interrupt a capture in progress. It waits until you've stopped recording before offering observations.

## When Bower withholds a source

In chat, when Bower searches the web, opens a web page, reads a file from your workspace or opens a document from a connected app, it first checks the text for instructions aimed at the assistant, such as hidden text telling it to ignore your request or send your notes elsewhere. If it finds any, Bower doesn't use that source. It tells you the source was blocked by its content safety check and answers from everything else. Your own notes and protocols, files you attach directly to a message, and live agent mode aren't checked.

The check catches most such instructions, not every one, so read what Bower reports from an outside source with the care you would give the source itself. Now and then a legitimate source is blocked, most often a page that quotes such instructions, like an article about AI security. If you need it, open the source yourself and paste the parts you need into the chat, and use the thumbs down on the reply to tell us.

## Bower or search?

Use [search](/ai-and-search/hybrid-search) to find a note or file you know exists. Use Bower to answer a question, summarize, compare, research the literature, or make changes, with an answer that cites its sources.

To rate a reply, use the thumbs up or down beneath it; see [Feedback](/workspaces-and-account/feedback).
