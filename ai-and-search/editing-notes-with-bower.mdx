---
title: "Ask Bower to edit a note"
description: "What Bower can change in a note when you ask in chat or by voice in Live: table cells, rows and columns, list items, headings, tasks, callouts, code blocks and formatting."
---

Ask Bower to change part of a note, in [chat](/ai-and-search/bower-ai-assistant) or by voice in [Live](/ai-and-search/live-agent-mode), and it edits only the part you named. The rest of the note stays exactly as it was, so a cell value or a ticked task never rewrites the paragraph next to it.

Name the note and the part you mean, such as the table, the step or the heading, the same way you would to a colleague.

## What can Bower change in a table?

| Ask Bower to | For example |
| --- | --- |
| **Fill or change a cell**, including an empty one | *"In the plate layout table, put 0.42 in the OD600 column for sample B3"* |
| **Add a row** | *"Add a row for sample 14 to the buffer table"* |
| **Remove a row** | *"Delete the row for the failed run on Tuesday"* |
| **Add a column** | *"Add a column called Incubation time after Temperature"* |
| **Remove a column** | *"Remove the Notes column from the reagent table"* |

## What can Bower change in lists, callouts and toggles?

| Ask Bower to | For example |
| --- | --- |
| **Add, change or remove a list item** | *"Add 'Check the pH meter calibration' to the prep checklist"* |
| **Tick or untick a task** | *"Tick off 'Autoclave the media'"* |
| **Add, change or remove a callout** | *"Add a warning callout under step 3 saying the reagent is light sensitive"* |
| **Change a callout's type**: info, warning, tip or error | *"Make the note about phenol a warning instead of a tip"* |
| **Add, change or remove a toggle** | *"Add a toggle called Raw readings at the end"* |
| **Restart a numbered list** at a different number | *"Start the second list of steps at 5"* |

## How do I change a heading or a code block?

| Ask Bower to | For example |
| --- | --- |
| **Change a heading's level** | *"Make Results a heading 2"* |
| **Change a code block's language** | *"Set the language of the analysis script to R"* |

## Can Bower format text in a note?

Yes. Bower can add or remove bold, italic, underline, strikethrough, highlight, subscript, superscript and links, on a whole block or on an exact phrase within it.

- *"Bold the final concentration in the summary"*
- *"Highlight 'do not vortex' in step 4"*
- *"Make the 2 in CO2 subscript"*
- *"Link 'Smith et al. 2024' to its DOI"*
- *"Remove the strikethrough from the second paragraph"*

## What will Bower not do?

- **Format inline code or an empty block.** Text shown as inline code keeps its own style, and an empty paragraph has no text to format.
- **Place an image** in a note this way. Insert images yourself; see [Images](/capture/editor#images).

If you ask for something that is already true, such as ticking a task that is already ticked, the request succeeds and the note doesn't change.
