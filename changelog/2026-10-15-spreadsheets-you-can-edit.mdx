**Shipped 2026-10-15 · Organization**

Until now, a `.csv` or `.xlsx` in Bower was a file Bower could read. It's now a
spreadsheet you work in: plate maps, sample manifests and instrument exports
stay next to the notes and protocols they belong to, and you no longer round-trip
through Excel to change a value.

## What's new

- **A spreadsheet in your workspace.** Choose **Create (+) > Spreadsheet** to
  start one from scratch or import a `.csv` or `.xlsx`. A spreadsheet file you
  upload or attach in Bower Chat becomes a spreadsheet too, and an existing
  attachment has **Convert to spreadsheet**.
- **The tools you expect.** Formulas, several sheets, sorting and filtering,
  charts, pivot tables and images. Changes save as you go.
- **Edit together.** Everyone with edit access works in the same workbook at
  once. **Version history** shows who changed what, and any version can be
  restored.
- **Ask Bower, with sources.** Bower reads live values, including formula
  results, and names the sheet and range behind each answer. Select cells and
  ask about "these".
- **Bower makes the change.** Ask it to fill in values, add a row by sample ID,
  format cells, sort, filter or add a chart. Each change shows on a
  **Spreadsheet updated** card with an **Undo** button.
- **Take it back out.** **Export** the whole workbook as Excel, or one sheet as
  CSV.

## Notes

- Workspaces in Restricted mode don't have native spreadsheets; their `.csv`
  and `.xlsx` files stay attachments.
- Live agent mode and connected AI apps can read spreadsheets but not change
  them.
