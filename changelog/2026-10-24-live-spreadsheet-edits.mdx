**2026-10-24 · Live**

Live agent mode could read a spreadsheet but not change it. Now you can ask
Bower to enter values while you talk.

## What's new

- **Values by voice.** *"Add a column with the temperature in Celsius"* or
  *"set the pH for the 48 hour reading to 7.05"*.
- **Only the cells you asked for.** Bower asks before replacing a value
  that is already there.

## Notes

- Formulas, formatting, charts, sorting, filters and undo stay in Bower
  Chat. See [Live agent mode](/organisation/spreadsheets#live-agent-mode)
  for the details.
- Workspaces in Restricted mode don't have native spreadsheets.
