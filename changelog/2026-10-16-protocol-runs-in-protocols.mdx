**Shipped 2026-10-16 · Protocols**

Runs now live with their protocol. The separate Protocol runs feed is gone, and
its old links open **Protocols**.

## What's new

- **Runs under each protocol.** In the protocol library, click a protocol's
  run count to show its runs beneath it. **Open runs** lists only protocols
  with a run still going.
- **A record for every run.** The steps as they were run, with **Done** times
  and the captures beside each step, plus a **Timeline**.
- **Runs and Versions in the protocol sidebar**, with run counts per version.
- **Labels that state facts:** **Open**, **Paused**, **Completed** or
  **Ended early**. A finished run is a fixed record, except that Live gives
  you 10 minutes to undo a misheard last step.
