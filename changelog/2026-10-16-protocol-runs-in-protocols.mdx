**Shipped 2026-10-16 · Protocols**

Runs now live with the protocol they belong to. The separate Protocol runs feed
is gone: open **Protocols**, and every protocol lists its runs underneath it.
Every run also has its own record, so you can read back exactly what happened
at the bench.

## What's new

- **Runs under each protocol.** In the protocol library, click a protocol's
  run count, such as **3 runs**, to show its runs as rows beneath it, 10 at a
  time. Turn on **Open runs** to list only protocols with a run still going.
- **Labels that state facts.** Each run says **Open**, **Paused**,
  **Completed** or **Ended early**, with how far it got, such as
  **Completed · 6 of 6 (1 skipped)**.
- **A record for every run.** Click a run to see the steps as they were run,
  **Done** times recorded by Bower, the photos, videos, voice notes and notes
  captured beside each step, and a **Timeline** of the whole run.
- **Honest about versions.** A run on a draft says so, and the record tells you
  when that draft's steps have changed since the run or when the protocol has
  a newer version.
- **Runs and Versions in the protocol sidebar.** On a protocol's page, **Runs**
  lists the runs of the version you're viewing, with **All versions** to see
  the rest, and each version in **Versions** shows how many times it was run.
- **Undo a misheard last step.** When Live finishes a protocol, say *"go back"*
  or *"undo"* within 10 minutes and Bower asks before reopening it. After that,
  a finished run is a fixed record.

## Notes

- Runs recorded before Bower kept step times show which steps were done,
  but not when.
- The `/capture-stream` link and the old Protocol runs help page now open
  **Protocols**.
