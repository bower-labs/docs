---
title: "Links"
description: "Keep shortcuts to pages outside Bower, such as GraphPad Prism Cloud projects, next to the rest of your work."
---

A link is a shortcut to a web page outside Bower. It sits in your workspace or in a collection like any other item, so the Prism Cloud project, vendor page, or shared drive folder behind an experiment lives next to the notes and data it belongs with.

Any web address that starts with `http://` or `https://` works. The most common use is a [GraphPad Prism Cloud](#prism-cloud) project.

## Adding a link

<Steps>
  <Step title="Open the Create menu">
    Click **Create** (the **+** button) and choose **Link**.
  </Step>
  <Step title="Paste the web address">
    Bower looks up the page's title and icon and fills them in. If you've already typed a title, Bower leaves it alone.
  </Step>
  <Step title="Check the title and icon">
    Edit the title if it isn't what your team will search for. For the icon, choose **Site icon** (the website's own icon) or **Bower icon** (the default link icon).
  </Step>
</Steps>

If the page has no title Bower can read, the title becomes the site's address, for example `app.graphpad.com`. Rename the link to something more useful.

Bower only accepts addresses that start with `http://` or `https://`. It refuses an address with a username or password written into it.

## Opening a link

Open a link the way you open anything else: click or double-click it in the workspace, or pick it from the page tree, search, or a link Bower mentions in chat. The page opens in a new browser tab, and Bower stays where you were.

Links show an open-in-new-tab mark, so you can tell them apart from items that open inside Bower.

## Editing a link

Right-click a link and choose **Edit link** to change its web address, title, or icon. Click **Refresh from page** to fetch the title and icon again, for example after the page has changed.

Everything else works as it does for other items. You can rename, move, copy, favorite, and share a link with the usual [access controls](/organisation/sharing-artifacts), or move it to Trash. See [Organizing your workspace](/organisation/organising-workspace) for the details.

To see only your links, choose **Links** in the workspace **Type** filter.

## Prism Cloud

To save a Prism Cloud project, open it in GraphPad, copy the address from your browser's address bar (it starts with `https://app.graphpad.com/`), and paste it into a new link.

- **The title shows `app.graphpad.com`.** Prism Cloud projects sit behind the GraphPad sign-in, so Bower can't see the project's name. Bower uses the site's address instead.
- **You need to be signed in to GraphPad.** The link opens the project in your browser, so sign in to GraphPad there first. Bower never signs in for you and never reads the project.

<Tip>
  Rename each Prism Cloud link after you add it, for example *Dose response, ELISA plate 3*, so you and your team can find it in search.
</Tip>

## Asking Bower

[Bower](/ai-and-search/bower-ai-assistant) can add links and change a link's address or title for you. For example:

> *"Save this Prism project link to my Assays collection."*
